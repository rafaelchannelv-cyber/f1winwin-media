# f1winwin-media

Картинки контент-конвейера @f1winwin. Репозиторий публичный: Buffer берёт картинки по прямым ссылкам.

Структура: одна папка на день `ГГГГ-ММ-ДД/`, внутри:
- `telegram/` — обложки 1080×1350 (RU), копия того, что ушло в бот
- `instagram/` — 1080×1350 (EN)
- `tiktok/` — 1080×1920 (RU)
- `threads/` — 1080×1350 (EN)

Прямая ссылка на файл: `https://raw.githubusercontent.com/rafaelchannelv-cyber/f1winwin-media/main/ГГГГ-ММ-ДД/<сеть>/<файл>`
